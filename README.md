# SistemaGestao1 — Gestão de Galeria

Sistema de gestão de aluguéis de uma galeria comercial.

## Perfis
- **Admin** (cadastrado apenas manualmente no banco): visão de todos os inquilinos, situação de pagamentos mês a mês, disparo de mensagens via WhatsApp.
- **Inquilino**: pagamentos mês a mês, upload de comprovantes, pendências, multas, contratos e aditivos, dia de vencimento, cobrança a partir do 3º dia após o vencimento, fotos das salas e informações da galeria, abertura de chamados.
